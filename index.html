Tabbed Slides

Slides for presentations, one tab per deck. Everything stays in this browser.

Keys in Present

→ or Space: next point, then next slide
← : previous point or slide
N: show or hide speaker notes
Esc: close

About Tabbed Slides

Version 2.0. For presentations. Video, animations between slides and advanced layouts are not supported yet.
Open file reads Tabbed Slides (.json) and PowerPoint (.pptx) files. From PowerPoint it keeps titles, text, notes, one picture and one chart per slide; layouts, shapes and animations are not kept. Save file saves in the format the deck was opened in; Save as PowerPoint saves a .pptx. In Chrome and Edge, Save writes back into the same file; in other browsers it goes to your downloads. Export HTML makes one file for any browser, with the same reveal keys. Export PowerPoint makes a .pptx file with editable charts and notes. Pictures are resized in your browser before saving.
